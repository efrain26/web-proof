# Validación de Credencial ISSET

Esta es una página estática que muestra información de validación de credenciales del Instituto de Seguridad Social del Estado de Tabasco.

## 🚀 Configuración de GitHub Pages

### Pasos para activar GitHub Pages:

1. Ve a tu repositorio en GitHub: `https://github.com/efrain26/web-proof`
2. Haz clic en **Settings** (Configuración)
3. En el menú lateral, busca **Pages**
4. En **Source** (Fuente), selecciona la rama `main`
5. Selecciona la carpeta `/ (root)`
6. Haz clic en **Save** (Guardar)
7. Espera unos minutos y tu página estará disponible en:
   ```
   https://efrain26.github.io/web-proof/
   ```
